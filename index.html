1
เปิดโปรเจกต์ Apps Script เดิม (URL /exec ที่ใช้อยู่) → ลบโค้ดเดิม วาง Code_CCA_v6.gs แล้วบันทึก
2
เลือกฟังก์ชัน setup กด Run และอนุญาตสิทธิ์ Drive/Sheets (จะสร้างไฟล์ "CCA_บันทึกเพิ่มเติม" ในโฟลเดอร์)
3
เลือก warmup กด Run เพื่ออ่านไฟล์ทั้งโฟลเดอร์ครั้งแรก (ถ้า Log ขึ้น complete:false ให้ Run ซ้ำ) แล้ว Run installTrigger 1 ครั้ง
4
Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy
Execute as: Me · Who has access: Anyone
5
กลับมาที่แอป กด "เชื่อมต่อ & โหลดข้อมูล" (URL ตั้งค่าไว้ให้แล้ว)
